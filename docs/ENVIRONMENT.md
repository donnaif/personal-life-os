# ENVIRONMENT — متطلبات البيئة

هذا الملف هو النسخة **العامة** القابلة للمشاركة. تفاصيل المضيف الخاص (الأسماء، المنافذ،
الخدمات القائمة) مقصورة على ملفات محلية غير منشورة.

## 1. المتطلبات الفعلية

| الأداة | الإصدار المُجرَّب | ملاحظة |
| --- | --- | --- |
| Node.js | **24.19.0** (الحد الأدنى 22) | يستخدم `node:sqlite` المدمج. |
| npm | 11.17.0 | يُستخدم **npm workspaces** (لا pnpm/yarn/bun). |
| Git | 2.55+ | — |
| Windows (للـdesktop) | Windows 10/11 أو Server 2022+ | `safeStorage` = DPAPI. |
| Linux/macOS (اختياري) | — | الـAPI والويب يعملان؛ تشفير الرمز يعتمد على Keychain/libsecret. |

لا حاجة إلى Docker ولا PostgreSQL ولا Redis.

## 2. أدوات غير مستخدمة (بقرار موثَّق)

| الأداة | السبب |
| --- | --- |
| Docker | لا عزل بحاويات؛ تشغيل أصلي عبر Node (انظر ADR-0011). |
| PostgreSQL | معزول عن أي قاعدة مشتركة؛ استُخدم `node:sqlite` (ADR-0003). |
| Redis | لا حاجة لطوابير؛ جدولة داخل العملية. |
| Rust/Cargo | يمتنع Tauri؛ اختير Electron (ADR-0006). |
| Android SDK/Gradle | مؤجل لمرحلة لاحقة (ADR-0007). |
| Drizzle/Next/Tailwind | ذُكرت في تخطيط أولي ثم استُبعدت: SQL مباشر + React/Vite/CSS متغيّرات. |

## 3. منافذ التطوير

| المنفذ | الخدمة |
| --- | --- |
| `127.0.0.1:3100` | الـAPI (`npm run dev:api`). |
| `127.0.0.1:3101` | واجهة التطوير Vite (`npm run dev:web`) — توكّل `/api` إلى 3100. |
| `127.0.0.1:3105` | خادم تطبيق سطح المكتب (ثابت؛ منافذ بديلة 3106/3107/3102/3103). |

كل الخوادم على `127.0.0.1` فقط، بلا `0.0.0.0`.

## 4. متغيّرات البيئة

انسخ `.env.example` إلى `.env` (غير مُتتبَّع). القيم الفعلية لا تُكتب في أي ملف مُتتبَّع.

| المتغيّر | الغرض |
| --- | --- |
| `JWT_SECRET` | توقيع رموز الـAPI — قيمة عشوائية طويلة. |
| `LIFEOS_API_URL` / `--api=` | وجهة الـAPI لتطبيق سطح المكتب. |
| `LIFEOS_DESKTOP_PORT` / `--port=` | منفذ خادم سطح المكتب. |
| `LIFEOS_E2E_EMAIL` / `LIFEOS_E2E_PASSWORD` | بيانات الدخول المستخدمة في تحقّق `--smoke` فقط. |
| `GITHUB_PERSONAL_ACCESS_TOKEN` | (بيئة المطوّر) لـMCP الخاص بـGitHub — لا يُكتب في ملف. |
