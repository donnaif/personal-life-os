# HANDOFF — دليل الاستئناف

**الغرض:** أي محادثة/مطوّر جديد يفتح المشروع يعرف — في دقيقتين — أين توقّف العمل، وما الخطوة
التالية، وكيف يتحقّق من أن كل شيء سليم. هذا الملف يُحدَّث في نهاية كل مرحلة.

**آخر تحديث:** 2026-10-19 · **المالك:** `donnaif` · **المستودع العام:**
https://github.com/donnaif/personal-life-os (`main`).

---

## 1. الصورة السريعة

| الطرف | المسار | الحالة |
| --- | --- | --- |
| منطق المجال | `packages/core` | مكتمل — اختبارات شاملة |
| الـAPI | `apps/api` | مكتمل — Fastify 5 + `node:sqlite`، منفذ 3100 |
| الويب | `apps/web` | مكتمل — React 19 + Vite، منفذ 3101، RTL + فاتح/داكن |
| سطح المكتب | `apps/desktop` | مكتمل — Electron 44، منفذ 3105، مُحزَّم ومختبَر فعليًا |
| Android | — | **لم يبدأ** (يحتاج SDK/Gradle) |

## 2. كيف تتأكد أن كل شيء يعمل (5 دقائق)

```powershell
npm install
npx vitest run            # المتوقع: 14 ملفًا / 135 اختبارًا ناجحًا
npm run typecheck         # المتوقع: بلا أخطاء (4 مشاريع)

# الـAPI + الويب
npm run dev:api           # نافذة 1 → 127.0.0.1:3100
npm run dev:web           # نافذة 2 → 127.0.0.1:3101

# تطبيق سطح المكتب (يحتاج الـAPI يعمل + حساب موجود)
npm run build:web
npm run smoke:desktop     # المتوقع: ok=true و17 خطوة كلها true
```
- إن لم يكن هناك حساب: أنشِئه من صفحة الدخول في الواجهة (أول مستخدم = المالك)، ثم مرّر
  بياناته لمتغيّرات `LIFEOS_E2E_EMAIL`/`LIFEOS_E2E_PASSWORD` لو أردت تشغيل الفحص الآلي.
- بعد الانتهاء: **أوقف** خوادم التطوير التي شغّلتها (لا تتركها على مضيف مشترك).

## 3. ما أُنجز آخر مرة (Phase 3 — سطح المكتب)

- غلاف Electron كامل بمعمارية: خادم محلي يخدم `apps/web/dist` + وكيل `/api` (يحذف البادئة)،
  نافذة آمنة (`contextIsolation`/`sandbox`، بلا `nodeIntegration`)، منع المنبثقات/`webview`/
  الأذونات/التنقّل الخارجي، CSP للتطوير والإنتاج، جسر preload ضيق مع تحقّق من كل IPC.
- رمز التحديث: `safeStorage` (DPAPI) + `desktop-state.json` في مجلد التطبيق (لا `localStorage`).
- إشعارات Windows اختيارية (opt-in) بنافذة 10 دقائق وحاجز 5 دقائق ومنع تكرار دائم.
- قائمة عربية/إنجليزية + tray + حفظ أبعاد النافذة + أيقونة مولَّدة برمجيًا.
- حزم: `npm run package:win` → `apps/desktop/release/Personal Life OS-win32-x64/`.
- تحقّق فعلي من الحزمة: **17/17 خطوة** (تسجيل دخول حقيقي، رمز مشفَّر خارج `localStorage`،
  ثبات الجلسة بعد إعادة التحميل **وبعد إعادة التشغيل**، صفر أخطاء طرفية).

### عيوب حقيقية اكتُشفت وأُصلحت (للاستفادة، لا للإخفاء)
1. **فقدان الجلسة عند كل إقلاع**: كان منفذ الخادم المحلي عشوائيًا فيتغيّر أصل الواجهة ويضيع
   `localStorage` → منفذ ثابت 3105 + مخزن ملف شخصي مشفَّر (ADR-0014/0015).
2. **حزمة ناقصة**: `extraResource` كان ينسخ المجلد باسمه فتصبح الأصول في `resources/.stage/web`
   → التطبيق يخرج بالرمز 2. الحل: staging إلى `.stage/web` + تحقق بعد الحزم.
3. **BOM في ملف الإعدادات** كان يُصفّر إعدادات المستخدم صامتًا → تحمّل BOM + اختبارات.
4. **windows path realpath**: عدم تطابق المسار المختصر كان يرفض ملفات مشروعة.

## 4. الخطوة التالية (واحدة فقط، بترتيب الأولوية)

1. **Android** (المسار الأكبر): تهيئة Kotlin + Compose، استهلاك نفس عقود الـAPI
   (`/auth/*`, `/tasks`, `/sessions`, `/habits`, `/reports`)، ويُفضَّل بدءًا بمرجع العقود من
   `packages/core`. يحتاج موافقة على تنزيل Android SDK/Gradle.
2. **نواقص الـAPI** (قيمة عالية، جهد أقل) — لا تُقلَّد في الواجهة قبل وجود endpoint:
   قراءة سجلات العادات، إدارة التصنيفات، استعادة مهمة محذوفة، تعديل الملف الشخصي، pagination.
3. **`eslint`** لتشغيل `npm run lint` (البند الوحيد المعطّل في سلسلة الجودة).
4. **`LICENSE`** للمستودع العام (قرار المالك).
5. تحسينات مؤجلة في سطح المكتب: تشغيل الـAPI مع التطبيق، وضع offline (يحتاج قرارًا معماريًا
   وADR قبل أي كود — لا تدّعِ دعمه قبل تنفيذه).

## 6. محلي فقط — لا يُنشر

هذه موجودة على جهاز المالك ومُستثناة في `.gitignore` لأنها تصف مضيفًا إنتاجيًا خاصًا بمشاريع
أخرى: `docs/server/` (جرد الخدمات، توزيع المنافذ، سلامة النشر) و`docs/ENVIRONMENT_AUDIT.md`.
إن احتجت تفاصيل المضيف فاطلبها من المالك؛ لا تُعِد إنشاءها في المستودع العام.

## 7. القيود المعروفة (اقرأها قبل أن تعد بشيء)

- لا وضع offline، ولا مزامنة متعدّدة الأجهزة، ولا تشغيل تلقائي للـAPI من الديسكتوب.
- لا توقيع رقمي للحزمة → تحذير SmartScreen متوقّع.
- `notifiedSessionIds` يقتصر على 200 معرّفًا (الأقدم يُزاح).
- تشغيل `--smoke` على ملف التعريف الحقيقي يترك معرّفات اختبارية؛ استخدم `--profile-dir`.
- الحالة على المضيف المشترك: لا تُشغّل أكثر من خادم تطوير واحد (الذاكرة محدودة).
