# SECURITY REVIEW — مراجعة الأمان

> تُحدَّث مع كل مرحلة. لا أسرار أو كلمات مرور في هذا الملف.

## 1. المبادئ المطبّقة

- **لا أسرار في Git:** `.env` مستثنى؛ `.env.example` آمن فقط.
- **لا كشف عام:** كل الخدمات على `127.0.0.1` في التطوير.
- **تحقق مزدوج:** تحقق مدخلات على الخادم (Zod) بغضّ النظر عن الواجهة.
- **استعلامات مُعاملة:** Drizzle ORM (مُعاملة افتراضيًا) → منع حقن SQL.
- **نطاق محدود:** قاعدة SQLite معزولة، مستخدم DB مقيّد (مبدأ أقل صلاحية للأدوار لاحقًا).

## 2. عناصر مخطط لها

- طريقة مصادقة: password hashing (bcrypt/argon2) + JWT access + refresh rotate.
- تحديد معدل الطلبات (`@fastify/rate-limit`).
- عناوين CORS محدّدة صراحة من `.env`.
- رؤوس أمان (Helmet-like) على API.
- إدارة أخطاء لا تكشف تفاصيل حساسة.
- CSRF: غير مطبّق على API token-based، مع مراعاة عند إضافة ملفات تعريف ارتباط مستقبلًا.
- XSS: تعقيم مخرجات؛ React يهرّب افتراضيًا.
- سجلات بلا أسرار.
